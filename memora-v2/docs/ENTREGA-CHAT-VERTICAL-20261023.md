# Continuidad vertical también al cerrar el chat

Seguimiento del episodio09a810f. La conversación del truco usa la misma superficie vertical que explicación/piezas/cierre. Tras responder y recibir la réplica, desplazar continúa; se retira el botón principal redundante Terminar la conversación. El control equivalente de toque/teclado sigue disponible en el indicador inferior para accesibilidad.

No se avanza mientras hay pregunta, borrador o réplica pendiente. Escribir conserva envío explícito: el scroll no envía texto ni acredita respuesta. La identidad answer/reply reinicia la guardia del gesto para que la inercia no salte la réplica. El log no tiene otro scroll anidado en este modo. El chat legacy conserva sus controles, ayudas, rescate, Eco y checkpoints.

Pruebas React montadas del episodio verifican que desplazar con borrador no escribe ni termina, reanudación y réplica→gesto→cierre. Pruebas anteriores de chat/rescate permanecen compatibles. No es una partida física/móvil o validación de diversión. No cambian catálogo, medios, cuentas, cobertura ni motor de memoria. Resultado de build y contraste servido se registra aparte, sin confundir GitHub con despliegue.
