# El propósito visible antes de las piezas

Seguimiento del tramo ON MY COMPUTER. El encabezado de episodios preparados muestra el objetivo real de la lección durante la enseñanza, en lugar de «Descubre cómo decirlo». Ordenador: «Avisa para que no apaguen tu ordenador». Llaves y cama conservan su título específico. En montaje/conversación siguen las instrucciones de fase y al terminar el cierre habitual.

No agrega introducción, botones, temporizador o estado; no cambia preparación ni respuestas. El objetivo también se ve cuando una estructura conocida permite abreviar I/AM y cuando se reanuda la enseñanza. Episodios antiguos sin aplicación preparada conservan el encabezado anterior. Las advertencias de guardado permanecen visibles.

Prueba: entrar o retomar enseñanza de una aplicación preparada; entender para qué servirá el mensaje antes de pasar sus piezas. Inspección visual/móvil y aceptación humana pendientes; pruebas React enfocadas y build registrados en checkpoint, no diversión acreditada.
