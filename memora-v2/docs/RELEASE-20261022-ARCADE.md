# Corrección de repetición y progresión

Motivo: partida humana con quince vueltas sobre BRUSH y petición de montar piezas antes de escribir.

- Se transmite la condición automática desde App al Arcade existente. Sorpresa: máximo tres retos (menos si falta contenido), retorno al recorrido mediante el cierre existente después del feedback/rescate. Sin ciclo cinco palabras/cinco gramática/cinco palabras.
- Gramática agrupa preguntas/ranuras de una misma frase, incluidas contracciones I’m/I am. No completa quince rondas reciclando un único mensaje. Arcade manual para al agotar el lote y repetir requiere decisión explícita.
- La reutilización de estructura ya no retira el ordenado. Conserva la restauración por identidad de tareas pendientes y todo el progreso.
- Sin contenido editorial, cuentas, permisos, datos reales ni piloto. Tres retos es un límite de producto provisional, no validación pedagógica.

Verificación: pruebas enfocadas de cierre automático tras acierto/timeout y rescate, lote manual de una frase, propagación del modo, construcción antes de escritura y continuidad de App. Build de producción correcto. No se atribuye partida móvil ni escucha real a los tests.
