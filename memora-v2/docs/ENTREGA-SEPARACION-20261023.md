# La sorpresa no repite lo que acabas de hacer

Sobre a0cfc2c. Inicio ya selecciona gramática por preparación; esta entrega no restaura ni rehace la antigua cuota de cuatro misiones. El hueco corregido estaba al terminar: Arcade podía evaluar de nuevo la misma escena inmediatamente.

La selección automática existente deja fuera las escenas de las últimas tres acciones distintas respondidas. Se deriva del journal ya guardado, sin otro contador persistente, scheduler, algoritmo de olvido o cambio de fechas SRS. Navegar, completar, escuchar modelos y repetir una reparación o la misma pregunta con otro ID no rellenan la separación. Los empates de fecha se tratan conservadoramente para que un orden distinto tras sincronizar no invente distancia.

Solo afecta la sorpresa automática. Arcade voluntario sigue disponible. Si no hay otra práctica preparada, se conserva la sorpresa pendiente y se puede continuar con las palabras; no inventar un reto ni repetir para cubrir una cuota. Los requisitos de significado/versión y opciones conocidas permanecen. La separación de tres acciones es un criterio de variedad del producto, no demuestra retención o un instante exacto de olvido.

También se distingue preparar una sorpresa de continuar: una petición automática sin material no puede retirar el feedback del ejercicio recién terminado. Solo la continuación explícita permite salir de él. El pool queda congelado durante la sesión para que responder no cambie a mitad el reto o borre su resultado.

Pruebas de dominio cubren separación, reparaciones, IDs aleatorios, modelos, eventos sin respuesta, empates y recarga. App montada verifica que el cierre sigue visible20segundos, no hay modal inmediato, la sorpresa sigue pendiente y el alumno puede abrir Arcade manualmente. No modifica alumnos reales, catálogo o medios. No acredita diversión, memoria diferida o cobertura del curso.
